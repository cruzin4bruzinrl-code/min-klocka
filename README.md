# Min klocka för Android

En liten app som håller kontakten med klockan i bakgrunden och gör klockans musikknappar till telefonens medieknappar.
Den har ingen internetbehörighet. Nyckeln till klockan klistras in i appen och sparas bara i telefonen.

Varje ändring på den här grenen byggs av GitHub och läggs upp under Releases som `min-klocka.apk`.
